# eval_8k_v1 — 8-K 事件评估 prompt（版本 1，2026-07-10 生效）

> 纪律：本 prompt 是 H1 forward test 的一部分。运行期间不得修改。任何修改 → 另存 v2 并将 H1 样本计数清零。

## 评估者收到的输入

- ticker、公司名、市值、行业、20 日均成交额
- 8-K 提交时间（accepted datetime, ET）、item 列表
- 8-K 正文全文（含 press release exhibit 若有）
- 该股此刻相对信号可得时点的价格变动（若可得：当日涨跌幅）

## 评估指令（对评估 agent 的原文）

你是一个事件驱动分析师。阅读这份 8-K 全文，只回答一个问题：**未来 1–2 个交易日，这份公告对股价的方向性影响**。

规则：
1. 先判断这个事件是否已经是旧闻（此前已有新闻/此 8-K 只是走流程确认）。旧闻 → skip。
2. 判断事件的实质经济影响：改变盈利能力/生存概率/被收购概率的 → 有实质；纯程序性（换审计师日常轮换、年会结果、高管例行变动）→ skip。
3. 若已知当日价格变动：判断价格是否已充分反应。一个 +2% 的重大利好可能仍未定价完（continuation），一个 +30% 的利好大概率已定价（skip）。
4. 谨慎默认：拿不准 → skip。conviction=3 应当稀少（预期 <20% 的评估给 3）。
5. v1 只做 long。明确利空输出 skip 并在 note 里标注 "would-short"（用于日后 H1b）。

输出 JSON：
```json
{
  "ticker": "...",
  "direction": "long" | "skip",
  "conviction": 1 | 2 | 3,
  "thesis": "一句话：什么事件、为什么市场会在1-2天内重估",
  "staleness_check": "为什么这不是旧闻",
  "priced_in_check": "为什么还没定价完",
  "note": ""
}
```

conviction 定义：
- 3 = 事件实质重大、方向明确、有理由相信未充分定价 → 执行开仓
- 2 = 方向倾向明确但有一个明显疑点 → 影子记录，不交易
- 1 = 弱信号 → 仅记录
